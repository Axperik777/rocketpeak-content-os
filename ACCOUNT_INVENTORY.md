# Инвентаризация Facebook-активов

Источник: интерфейс «Страницы, которыми вы управляете», скриншот пользователя и существующий файл `Facebook/Контент/07-статус-оформления.md`.

| Название | Тип | Рабочая роль | Публикация |
|---|---|---|---|
| AD Lumeo | Личный профиль Facebook | Владелец доступов, «кинг» в рабочем сленге | Только вручную |
| RocketPeak | Facebook Page | Основная страница агентства | Можно подключить через официальный API |
| Arsen | Facebook Page | Экспертная страница Арсена | Можно подключить через официальный API |
| Ad Lumeo | Facebook Page | Дополнительная агентская страница | Можно подключить после решения о её роли |
| Barmaglot Tbilisi | Facebook Page, деактивирована | Клиентский актив | Не подключать |

## Важно

- «Фан-пейдж» и Facebook Page в данном контексте — одно и то же.
- «Кинг» — не объект или роль Meta. Это сленговое название личного профиля, на котором держатся доступы.
- Верхний `AD Lumeo` и нижний `Ad Lumeo` — разные активы: личный профиль и страница.
- Связанный Instagram-профессиональный аккаунт пока не определён и не должен считаться подключённым без проверки в Meta Business Suite.
