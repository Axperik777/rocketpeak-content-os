# RocketPeak Content OS

**Рабочая папка:** `C:\Users\Mylaptop\Desktop\MARKETING\Приложение`

**GitHub:** `https://github.com/Axperik777/rocketpeak-content-os`

**Основная ветка:** `main`

**Публичная сборка:** GitHub Pages

**Backend:** Supabase.

Публичная демо-версия: `https://axperik777.github.io/rocketpeak-content-os/`

Демо работает без Meta API. После входа материалы синхронизируются с приватной базой Supabase; локальное хранилище используется для миграции и резервного состояния интерфейса.

Локальное приложение для подготовки, согласования и планирования контента RocketPeak.

## Запуск

Основной способ: ярлык `RocketPeak Content OS` на рабочем столе.

Резервный способ: запустить `Launch-ContentOS.ps1` или `START.cmd` из этой папки. После запуска приложение доступно по адресу `http://127.0.0.1:4173/`.

Лаунчер:

- запускает локальную production-сборку через Vite Preview;
- ждёт готовности сервера;
- открывает приложение в отдельном окне Chrome;
- сохраняет диагностический лог в `runtime/launch.log`.

## Что работает

- очередь материалов и фильтры;
- календарное представление;
- карта Facebook-активов;
- создание и локальное редактирование материалов;
- статусы: черновик, проверка, согласовано, пропущено;
- восстановление пропущенных материалов;
- сохранение контент-плана по версионированной схеме v2 в `localStorage` браузера;
- автоматическая миграция старых локальных данных;
- импорт и экспорт проверяемого JSON v2;
- экспорт данных в JSON;
- адаптивный интерфейс для desktop и mobile.
- авторизация и синхронизация через Supabase с RLS по владельцу;
- приватная загрузка медиа и серверная проверка файлов;
- очередь публикаций, audit log, защита от дублей и выключенный по умолчанию safety gate;
- публичные страницы Privacy Policy, Terms и Data Deletion для подготовки Meta App.

## Текущие ограничения

- Meta, Instagram и Telegram не подключены;
- автоматическая публикация отключена;
- Meta, Instagram и Telegram ещё не подключены;
- регистрация Meta for Developers временно ограничена защитой аккаунта;
- серверная публикация и OAuth остаются выключенными до проверки активов и разрешений.

Приложение не обходит антифрод Meta и не использует cookies, пароли или браузерные автоклики. Будущая интеграция допускается только через официальные API, с ручным подтверждением публикации, защитой от дублей, журналом действий и консервативными лимитами.
