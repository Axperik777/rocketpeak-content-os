# Артефакты проверок

Эта папка относится только к RocketPeak Content OS и хранит воспроизводимые результаты аудита и материалы для TikTok App Review.

- `lighthouse.json` — исходный отчёт Lighthouse;
- `lighthouse-final.json` — итоговый отчёт после исправлений;
- `tiktok-app-icon-1024.png` — иконка для карточки приложения;
- `tiktok-app-review-demo.mp4` — демонстрация сценария для проверки TikTok;
- `tiktok-app-review-demo-contact-sheet.png` — контактный лист видео.

Не использовать эти файлы как ресурсы runtime и не переносить в `public/` без отдельной необходимости. При обновлении проверки заменять файл осознанно и фиксировать дату в `STATUS.md`.
