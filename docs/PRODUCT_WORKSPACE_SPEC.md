# RocketPeak Workspace — продуктовый контур

## Задача

Один внутренний инструмент для двух сотрудников без CRM, постановщика задач и рекламных кабинетов.

## Основные разделы

1. **Обзор** — выбор рабочего контура: клиентские проекты или собственный проект RocketPeak.
2. **Проекты** — список клиентов. Внутри каждого проекта находятся обзор, постоянный бриф, креативы и файлы.
3. **RocketPeak** — отдельный собственный проект: контент, креативы, календарь, аккаунты и подключения.

Глобальных разделов «Создать», «Библиотека» и «Подключения» нет: действие всегда выполняется внутри конкретного проекта.

## Жёсткие границы

- клиентские материалы никогда не попадают в очередь публикации автоматически;
- AdsPower, прокси, рекламные кабинеты и запуск рекламы остаются вне приложения;
- нет лидов, сделок, задач, комментариев, ролей и контроля сотрудников;
- оба участника рабочего пространства имеют одинаковый доступ;
- удаление сначала переводит объект в корзину;
- генерация не означает согласование или публикацию;
- публикация возможна только после ручного подтверждения точной версии.

## Модель результата креативной лаборатории

Каждый результат хранит проект, формат, канал, гипотезу, текст, CTA, референсы, автора, номер версии и время создания. Это позволяет вернуться к исходнику без переписки и не терять удачные варианты.
