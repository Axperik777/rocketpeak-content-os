# TikTok Direct Post — готовность к аудиту

## Реализовано в коде

- актуальные данные автора запрашиваются перед настройкой публикации;
- показаны nickname и username подключённого аккаунта;
- список видимости берётся из `privacy_level_options`, без значения по умолчанию;
- комментарии, Duet и Stitch выключены по умолчанию и учитывают запреты аккаунта;
- добавлены настройки собственного бренда и платного партнёрства;
- платное партнёрство нельзя совместить с видимостью `SELF_ONLY`;
- перед публикацией требуется подтверждение TikTok Music Usage Confirmation;
- сервер повторно проверяет все обязательные решения;
- очередь показывает состояния `pending`, `processing`, `published`, `failed`;
- видео отображается в превью до согласования.

## Перед отправкой заявки TikTok

1. Применить миграцию `20260729143000_tiktok_audit_controls.sql`.
2. Развернуть `tiktok-creator-info` и обновлённую `publish-queue`.
3. Настроить безопасный запуск `publish-queue` раз в минуту без хранения секрета в Git.
4. Записать демонстрацию: вход, выбор видео, аккаунт автора, видимость, взаимодействия, disclosure, согласие, подтверждение, статус.
5. В заявке описывать продукт как инструмент для авторов и компаний, а не как закрытый загрузчик для собственных аккаунтов.
6. После одобрения провести отдельный тест `PUBLIC_TO_EVERYONE` на публичном аккаунте.

## Gate

До одобрения TikTok публичную публикацию не считать доступной. Текущий доказанный режим — приватный аккаунт и `SELF_ONLY`.
